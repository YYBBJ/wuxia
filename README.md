# 武侠文字小游戏

一个使用 Java 编写的命令行武侠小游戏。玩家可以闯荡江湖、随机遭遇敌人，使用武学或调息应战，并通过战斗积累修为、提升等级。

## 功能

- 创建侠客并查看气血、内力、等级和修为
- 外出历练，随机遭遇普通敌人
- 使用不同武学攻击，或使用「静心诀」恢复气血
- 调息恢复内力，也可以选择撤退或在战斗中逃跑
- 击败敌人后获得修为；升级会提升气血和内力上限并恢复状态
- 战斗中有随机暴击和敌人重击

## 环境要求

- JDK 21 或更高版本
- Maven 3.6 或更高版本

## 编译与运行

在项目根目录执行：

```bash
mvn clean package
java -jar target/wuxia-1.0-SNAPSHOT.jar
```

程序启动后，输入侠客名号，再根据主菜单和战斗提示输入数字进行操作。

## 操作说明

### 主菜单

| 输入 | 操作 |
| --- | --- |
| `1` | 外出历练并遭遇敌人，可选择战斗或撤退 |
| `2` | 查看侠客状态 |
| `0` | 退出游戏 |

### 战斗

| 输入 | 操作 |
| --- | --- |
| `1` | 选择并施展武学 |
| `2` | 调息，恢复 15 点内力 |
| `3` | 逃离战斗 |

初始武学包括「流云剑式」「长虹贯日」和「静心诀」。每种武学消耗不同内力；内力不足时无法施展。

## 项目结构

```text
src/
├── main/java/com/it/
│   ├── common/       # 武学数据模型
│   ├── core/         # 游戏入口与战斗流程
│   ├── enemy/        # 敌人和敌人工厂
│   └── player/       # 玩家属性、武学和升级逻辑
└── test/java/        # 测试代码
```

项目使用 Maven 管理构建，Lombok 用于生成数据类的常用方法。
